# Практическая №4: Формы и localStorage

**Вариант:** 6, проверка пользовательского интерфейса. **Имя/группа:** укажите перед сдачей.

## Запуск
`npm test` — проверки сервисного кода и модулей хранения/валидации; `npm start` — локальный сайт `http://127.0.0.1:5504/`; страницу с индивидуальными задачами открыть `http://127.0.0.1:5504/?dataset=variant`; браузерная проверка `http://127.0.0.1:5504/checks.html`.

## Архитектура
`data.js`: общий и индивидуальный наборы; `task-service.js`: неизменяющие функции модели; `task-selectors.js`: фильтры `all`, `pending`, `completed`; `task-view.js`: текстовые карточки, сводка, пустое состояние; `main.js`: обработчики событий и состояние. Изображения/HTML из названия не исполняются (`textContent`).

## Проверки и вывод
Реализован тестовый HTML-сценарий в `checks.html` (самостоятельный набор; не является копией официальных тестов преподавателя). При запуске нужно отдельно записать фактический результат страницы, проверить клавиатурное управление и скриншот отладки.

В ПР4 ключи `tip-js-practice-04:demo` и `tip-js-practice-04:variant` разделены. Данные хранятся как JSON `{version:1,tasks}`. Неверные данные или ошибка чтения приводят к `fallback`; reset удаляет только нужный ключ. Форма допускает только нормализованное название 1–100 символов, ID без дубликата, один из трёх приоритетов. Успешное редактирование сохраняет поле `completed`.
