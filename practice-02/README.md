# Практическая №2 — модель задач

**Вариант 6**, тема — проверка пользовательского интерфейса. **Автор/группа:** дополнить.

Команды: `npm run examples`, `npm start`, `npm run check`.

Реализованы девять функций `createTask`, `findTaskById`, `getPendingTasks`, `getTaskTitles`, `getTaskStats`, `addTask`, `setTaskCompleted`, `renameTask`, `removeTask`; дополнительно `updateTask` для ПР4. Отказы возвращаются `{ok:false,error}`; переданные объекты не изменяются.

Индивидуальные задачи: `[11,23,37,41,58,64]`, из них выполнены первые 5. Начальная сводка: `6 / 5 / 1 / 83.3%`. Добавляется `id=80`, `priority=low`; статус `11` становится `true`, переименовывается `23`, удаляется `37`; повтор `80` отклоняется. Итог 6 задач, выполнено 4, прогресс `66.7%`.

На примере ссылок: spread создаёт новый массив, но вложенные объекты остаются общими; отсутствующий `return` у стрелочной функции даёт `undefined`, исправлено. Ожидаемый отказ не прерывает последующие операции.
