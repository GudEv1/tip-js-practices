# Практические работы по JavaScript — вариант №6

Готовый учебный проект с отдельными папками **practice-01** — **practice-06**. Основа — задания курса «Технологии индустриального программирования» (TIP-JS). Разделение ответственности: модель задач → DOM → localStorage → HTTP-клиент → интерфейс с API.

## Для WebStorm

1. Распакуйте архив, откройте папку **tip-js-practices** через `File → Open`.
2. Убедитесь, что Node.js доступен (`node --version`), рекомендуется Node.js 24 LTS.
3. Для проверки всех **Node.js**-скриптов в терминале корня выполните `npm test`. Внешние npm-зависимости не нужны.
4. Для браузерной проверки ПР3 отдельно откройте терминал в `practice-03`: `npm start`, затем `http://127.0.0.1:5503/checks.html`.
5. Для ПР4 запустите `npm start` в `practice-04`, затем `http://127.0.0.1:5504/checks.html`.
6. Для ПР6 запустите `npm start` в `practice-06`, затем `http://127.0.0.1:5506/checks.html`.
7. **Не запускайте** одновременно ПР5 и ПР6 на порту 5505; выключайте предыдущий сервер сочетанием `Ctrl+C`.

## Что проверено

- Все JS-файлы: синтаксис Node.js без ошибок.
- ПР2–ПР6: локальные тесты через `npm test`.
- ПР3/ПР4: ключевые взаимодействия в Chromium (список, фильтры, сводка, создание, редактирование, хранение, отклонение формы).
- ПР6: два ранее проблемных сценария проверены в браузере с имитацией API: создание ID35 и отклонение названия из пробелов без POST.

**Ограничение:** полный браузерный прогон всех `checks.html` в настоящем локальном HTTP-окружении выполнить здесь не получилось. Его необходимо провести в WebStorm и добавить фактический протокол к отчёту перед сдачей. Не следует путать тесты, входящие в этот архив, с оригинальными тестами преподавателя.
