# Практическая №1: основы JavaScript

**Вариант:** 6. **Автор:** указать ФИО и группу.

## Выполнение
- `node js/hello.js` — запуск Node.js, `typeof document` = `undefined`. В браузере — `object`.
- `node js/types.js` — проверка 10 выражений.
- `node js/progress.js` — вариант 6: 18 задач, 6 выполнено, осталось 12, прогресс **33.3%**, статус «В работе».
- `node js/plan.js` — 12 задач с лимитом 5: 3 дня (5, 5, 2).
- `node js/debug.js` — после исправления: выполнено 5, осталось 3, контрольная сумма 10.

## Отладка и теория
В исходной ошибочной программе «3» + «2» склеивалось в «32». Исправлено числовым преобразованием `Number`. Цикл с условием `< 4` пропускал число 4; теперь `<= 4`.
Результат `Number("")` — 0; `Number("text")` — NaN; `Boolean("false")` — true; `typeof null` — строка `object`.

## Граничные случаи
Нулевая пара задач даёт «Задач пока нет»; выполнено больше общего числа, дробные, отрицательные, строковые и свыше 1000 — ошибка. Нулевая дневная норма — ошибка.
