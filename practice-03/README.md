# Практическая №3: DOM и события

**Вариант:** 6, проверка пользовательского интерфейса. **Имя/группа:** Гудзь Евдркия Денисовна ЭФБО-05-25.

## Запуск
`npm test` — проверки сервисного кода; `npm start` — локальный сайт `http://127.0.0.1:5503/`; страницу с индивидуальными задачами открыть `http://127.0.0.1:5503/?dataset=variant`; браузерная проверка `http://127.0.0.1:5503/checks.html`.

## Архитектура
`data.js`: общий и индивидуальный наборы; `task-service.js`: неизменяющие функции модели; `task-selectors.js`: фильтры `all`, `pending`, `completed`; `task-view.js`: текстовые карточки, сводка, пустое состояние; `main.js`: обработчики событий и состояние. Изображения/HTML из названия не исполняются (`textContent`).
